# Freelance Lead Bot

Бот мониторит Telegram-каналы с фриланс-заказами и пересылает подходящие лиды в личку.

## Как работает

1. **Userbot** (левый аккаунт) подписывается на 15 фриланс-каналов и читает новые сообщения
2. Каждое сообщение прогоняется через фильтр ключевых слов (Python, бот, парсер, API и т.д.)
3. Если сообщение набирает нужный score — **бот** (@octoparcer_bot) пересылает его тебе

## Конфигурация

- **Бот:** задаётся через `TELEGRAM_BOT_TOKEN`
- **Доступ:** задаётся через `TELEGRAM_TARGET_CHAT_ID` / `ADMIN_CHAT_IDS` в `.env`
- **Каналов мониторится:** 13 (настраивается в боте или `sources.py`)
- **База данных:** SQLite (`data/leads.sqlite3`)

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Подписать чат на лиды |
| `/stop` | Отписать чат |
| `/status` | Статистика (источники, лиды, подписчики) |
| `/sources` | Список активных каналов |
| `/keywords` | Ключевые и стоп-слова |
| `/test <текст>` | Проверить, пройдёт ли текст фильтр |

## Запуск

```bash
# Установить зависимости
pip install -r requirements.txt

# Первый запуск (потребует авторизацию userbot — введи номер и код из Telegram)
python -m freelancer_bot

# На сервере через pm2
pm2 start "python -m freelancer_bot" --name freelance_bot --cwd /path/to/freelance_bot
```

## Файлы (не в git)

- `.env` — все токены и настройки
- `sessions/` — сессии Telegram (не удалять, иначе потребуется повторная авторизация)
- `data/` — SQLite база с лидами
